## Source revert

Worktree: `anki/victor/animProcess/src/cozmoAnim/`

### A1 — undo mic buffer trim

**`micData/micDataInfo.cpp` — `GetProcessedAudio`**

Restore copy-only (do **not** erase):

```cpp
AudioUtil::AudioChunkList MicDataInfo::GetProcessedAudio(size_t beginIndex)
{
  std::lock_guard<std::mutex> lock(_dataMutex);
  AudioUtil::AudioChunkList copiedData;
  const auto currentSize = _processedAudioData.size();
  if (beginIndex >= currentSize) {
    return copiedData;
  }
  auto chunkIter = _processedAudioData.begin() + beginIndex;
  const auto endIter = _processedAudioData.begin() + currentSize;
  while (chunkIter != endIter) {
    const auto& audioChunk = *chunkIter;
    ++chunkIter;
    AudioUtil::AudioChunk newChunk;
    newChunk.resize(kSamplesPerBlockPerChannel);
    std::copy(audioChunk.begin(), audioChunk.end(), newChunk.begin());
    copiedData.push_back(std::move(newChunk));
  }
  return copiedData;
}
```

### A1 timeout note (2026-07-20 fix)

First A1 deploy reset `_streamingAudioIndex=0` every take and reused it for timeout → stream never timed out → **NoCloud (đám mây lỗi)**. Fixed by accumulating `_streamingChunksSent` for timeout only.

### MicJobProbe (TEMP 2026-07-20)

Every ~10s `MicDataSystem` logs `MicJobProbe` (job count, processed/raw chunk ≈KB, collect flags, streaming state). Use with MemProbe: if anim RSS climbs while `nJobs=0` / `totalProc=~0KB`, leak is elsewhere (e.g. Picovoice); if `procChunks` climbs in idle, leftover `MicDataInfo` Collect. Remove after finding the leak.
